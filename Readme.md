
# TerraFind

TerraFind is a responsive image discovery interface designed to help users explore visual inspiration across nature, cities, animals, and architecture.

I chose a forest-green and warm-cream palette to create a calm, nature-inspired identity that feels distinct from the reference design.

I added quick-pick category chips so users can easily discover common search ideas, along with a sticky header that keeps the brand visible while scrolling.

The empty results grid is intentionally reserved for Part 2, when real image data will be fetched from an API.
